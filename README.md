# 판형 · 비즈니스 이미지 스튜디오

첨부 디자인 카드 8종을 바탕으로 캠페인, 제품 광고, 행사 포스터, 유튜브 썸네일, 책 표지, 메뉴판, 인포그래픽, 모바일 앱 화면을 제작합니다. 공통 프로젝트 지침과 용도별 확인 사항은 [PROJECT_GUIDE.md](PROJECT_GUIDE.md)에 있습니다.

## PC에서 모델로 제작하기

1. Python 3.9 이상과 Node.js를 설치한 PC에서 터미널로 `npm install -g @openai/codex`를 실행합니다.
2. `codex login`으로 이용 중인 ChatGPT 계정에 로그인합니다. `codex login status`에서 ChatGPT 로그인을 확인합니다.
3. 이 저장소를 내려받아 압축을 풀고 해당 폴더에서 Windows는 `py studio.py`, macOS·Linux는 `python3 studio.py`를 실행합니다. 브라우저가 열리지 않으면 http://127.0.0.1:8765 에 접속합니다.
4. 용도와 출력 비율을 고르고 내용을 입력합니다. ‘예시 불러오기’로 시작할 수도 있습니다. Astra 또는 Sol을 선택하고 ‘이미지 생성’을 누릅니다. 나온 시안별로 PNG를 저장합니다. 종료할 때 터미널에서 Ctrl+C를 누릅니다.

Astra는 `gpt-6-astra`, Sol은 `gpt-6.1-sol`로 Codex CLI에 전달됩니다. 선택한 모델의 이용 권한과 구독 잔여 한도가 필요합니다. 앱은 ChatGPT 로그인 상태를 확인하고 키 인증 환경변수를 제거한 뒤 실행합니다. 브리프가 구독 세션으로 전달됩니다. PC 모드는 모델이 작성한 벡터 그래픽을 지정 크기의 PNG로 렌더링합니다. 사진 기반 광고가 필요하면 아래 ChatGPT 제작 흐름에서 제품 사진을 함께 첨부하세요.

## 휴대폰에서 제작하기

앱의 단일 파일 버전 `studio-mobile.html`을 브라우저로 엽니다. 용도별 내용을 입력하고 ‘지시문 복사’ → ‘ChatGPT 열기’를 누릅니다. ChatGPT에서 사용 가능한 모델을 직접 선택하고 지시문을 붙여 넣어 전송합니다. 실물 제품 사진과 로고가 있으면 이 단계에서 함께 첨부합니다. 결과 이미지는 ChatGPT에서 저장합니다.

입력 초안과 모델 선택은 해당 브라우저의 로컬 저장소에 보관합니다. 저장소 이용이 제한된 브라우저에서는 현재 화면에서만 유지됩니다. 웹의 모델 선택은 사용자가 ChatGPT에서 확인할 희망 모델입니다. PC 서버는 해당 PC의 루프백 주소에서만 요청을 받습니다.
